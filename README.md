[# SkinzoneNaturelAdmin
Skinzone Naturel Admin System which provides the business Skinzone Naturel with management ,tracking of stock inlcuding products and treatments and How many people and the transaction that occured within a month 
](https://github.com/itudevs/SkinzoneNaturelAdmin/wiki)

## Development

The application source is written in TypeScript and uses Create React App.

```bash
npm install
npm start
```

Run the TypeScript compiler without emitting files:

```bash
npm run typecheck
```
